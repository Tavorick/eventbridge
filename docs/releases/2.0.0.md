# EventBridge 2.0.0

## Key changes

- Event delivery now runs through a central destination and dispatcher layer; Meta remains the only destination in this release.
- Browser attribution and privacy-scoped profile linking connect visits with Fluent Booking appointments.
- Selected Fluent Booking appointment types can create conversion opportunities.
- A manually confirmed conversion can send one or more existing server events.
- Admin pages support connections, conversions, and controlled profile maintenance.

## Upgrade

- The supported updater path is EventBridge 1.3.1 to 2.0.0.
- Existing migrations move database version 2 to 6 and add profile, context, and conversion storage.
- Existing settings, events, and stored state are preserved.
- WordPress 5.8 and PHP 7.4 remain the minimum requirements.

## Release and deployment

- The release expects exactly `eventbridge-2.0.0.zip` and `eventbridge-2.0.0.zip.sha256`.
- Consent/CMP integration is not included; verify the iubenda configuration before production deployment.
