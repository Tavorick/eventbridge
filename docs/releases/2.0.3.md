# EventBridge 2.0.3

## Key changes

- Adds a standalone **Telefoonafspraken** admin page and admin-bar shortcut for therapists and other users with the `publish_posts` capability.
- Limits every appointment listing, search and conversion action to Fluent Booking records whose `host_user_id` exactly matches the current WordPress user, including administrators.
- Shows only existing EventBridge conversion opportunities and reuses the established conversion service for delivery, retries, deduplication and final status handling.
- Presents appointment time, client contact details, appointment context and a simplified human-readable conversion status in a responsive owner-only interface.
- Keeps the existing EventBridge **Conversies** page and its `manage_options` behavior unchanged.

## Security and privacy

- Manipulated conversion identifiers, missing bookings, non-Fluent records and cross-owner requests fail closed before conversion execution.
- Searches remain grouped beneath the mandatory ownership filter and escaped wildcards cannot broaden access.
- Client data is escaped for owner-only rendering and is not added to EventBridge logs, diagnostics or release evidence.
- The therapist view exposes no delivery codes, request payloads, hashes, attribution identifiers or retry details.

## Validation

- The canonical isolated matrix passed on PHP 7.4 and PHP 8.3, including focused ownership and authorization tests, real Fluent Booking integration, browser harnesses, WordPress 5.8 compatibility, WooCommerce classic and HPOS, privacy scanning and source-integrity checks.
- Staging acceptance of the final therapist interface was reported successful before stable publication.

## Upgrade

- No database migration is required; `EVENTBRIDGE_DB_VERSION` remains 7.
- WordPress 5.8 and PHP 7.4 remain the minimum supported versions.
- Production upgrades should use the verified release ZIP and retain the previous package for rollback.
